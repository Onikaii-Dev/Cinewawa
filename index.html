Les paliers

🎬 Importer depuis Letterboxd

  1. Sur letterboxd.com (depuis un navigateur) : ton avatar → Settings → onglet Data.
  2. Clique « Export your data » → un fichier ZIP se télécharge.
  3. Dézippe-le (clic droit → Extraire tout).
  4. Dedans, prends ratings.csv (tes films notés) ou watched.csv (tout ce que tu as vu).
Les notes /5 sont converties en /10 (4½ ★ → 9), les dates de visionnage sont reprises, et les films déjà présents sont ignorés. Les affiches se récupèrent ensuite fiche par fiche avec 🔍.

⛩️ Importer depuis MyAnimeList

  1. Sur myanimelist.net (depuis un navigateur) : Profil → Settings → onglet Export.
  2. Choisis Anime List ou Manga List, puis « Export My List ».
  3. Un fichier .xml.gz se télécharge — tu peux le donner tel quel, le site le décompresse tout seul.
  4. Refais l'opération pour l'autre liste (anime et manga s'exportent séparément).
Les notes /10 sont reprises telles quelles, le statut est converti (Watching → En cours, Completed → Terminé…), et la progression aussi (épisodes vus, tomes et chapitres lus). Les titres déjà présents sont ignorés. Ensuite : 🖼️ Affiches partout pour les visuels.

☁️ Synchro cloud (GitHub)

Ta sauvegarde est stockée sur ton compte GitHub. Colle le même token sur chaque appareil (PC, téléphone…) et tout se synchronise automatiquement.
🔑 Créer mon token GitHub Page pré-remplie : nom « cinewawa », case gist cochée, sans expiration ↗
  1. Clique le bouton ci-dessus (connecte-toi à GitHub si besoin), descends tout en bas et clique « Generate token ».
  2. Copie le code ghp_… — il n'est affiché qu'une seule fois, garde-le dans tes notes.
  3. Colle-le ci-dessous puis Activer : ta sauvegarde cloud est créée.
  4. Sur ton téléphone : même site → ☁️ → le même token → Activer. Tout se retrouve.
Si GitHub affiche quand même une expiration, choisis « No expiration » dans le menu déroulant. Le pseudo se règle dans Mon Profil.
Il reste sur cet appareil et n'est envoyé qu'à GitHub.
